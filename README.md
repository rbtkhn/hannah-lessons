# Hannah Lessons

Lean, self-contained adult learning packages by Mira. This public collection contains teaching material, not personal career records, private learning history or correspondence.

## Start a lesson

Copy this folder URL into a family-approved ChatGPT chat and say **Begin this lesson**:

https://github.com/rbtkhn/hannah-lessons/tree/main/lessons/usage-data-next-step

[Open the pilot: From usage numbers to a useful next step](lessons/usage-data-next-step)

The folder displays its complete lesson in `README.md`. The tutor should retrieve that file, verify its identity and revision, then begin. You should not need to navigate individual files. Retrieval depends on the chat’s available tools; a public URL is not a guarantee that every account can load it.

If the chat cannot read the complete lesson, open the folder and use **Download raw file** on its README where available, then attach it. Alternatively copy the [complete raw text](https://raw.githubusercontent.com/rbtkhn/hannah-lessons/main/lessons/usage-data-next-step/README.md) and paste it into the chat. Say **Begin the lesson I supplied.** Attaching or pasting is a fallback, not the intended first step.

## Package design

Each folder contains one complete `README.md`: purpose, supplied evidence, opening, optional practice, tutor guidance and a revision marker. Add assets only when essential and explicitly referenced. The pilot needs no other files, personal data or account connections after loading.

The stable package ID identifies the activity. This pilot is deliberately unnumbered: a learner’s private lesson sequence may already contain other activities. Record a number only in the appropriate private record after identity is established. No preparation, repository publication or chat ending awards completion or capability.

Keep personal resumes, employer details, transcripts, learner observations, portraits, ledgers, review records and correspondence outside this public repository. Do not submit personal work through public issues. Private records may refer to the package ID, revision and commit actually used; this public collection does not receive those records automatically.

This is a prepared pilot. Folder-first retrieval and actual learner benefit still need testing in the intended ChatGPT account. A later repository revision does not update an attached file or an earlier chat automatically.
